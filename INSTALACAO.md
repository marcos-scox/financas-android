# Instalação do FinAI

## Teste imediato no Android

Abra o projeto no painel e use o QR code da seção de preview para abrir o FinAI no Expo Go. O celular precisa estar com acesso à internet. Esse modo é indicado para testar a interface e os lançamentos locais sem instalar um APK permanente.

## Aplicativo Android instalável

Para gerar o APK, use o botão **Publish** no painel de gerenciamento depois que este checkpoint estiver disponível. O processo de publicação gera o artefato Android para download. No celular, permita a instalação de fontes desconhecidas quando o Android solicitar, abra o APK baixado e confirme a instalação.

## Versão web instalável

A versão web pode ser aberta pelo endereço público do preview. No Chrome para Android, abra o menu do navegador e selecione **Adicionar à tela inicial** ou **Instalar aplicativo**, quando essa opção aparecer. Essa alternativa funciona como atalho instalável e mantém os dados no armazenamento local do navegador.

## Dados e privacidade

Os lançamentos desta versão são armazenados localmente no dispositivo por meio do AsyncStorage. Eles não são sincronizados entre aparelhos e não exigem cadastro para o funcionamento básico.
